# iOS 2.11.1 · build 75

修复 `v2.11.0` 更新后双生日合并展示与农历生日切换显示问题。

## 修复内容

- **双生日合并行完整展示公历与农历**：首页「即将到来」清单中的双生日合并条目改为双行清晰排布，标题下方完整展示 `公历 X月X日 · 农历 X月X日`，解决单行横向空间不足导致农历部分被截断的问题。
- **日期类型平铺直选**：新建/编辑页的 `新历生日 / 农历生日 / 节假日` 改为直接平铺切换，无需点开折叠菜单即可一眼选择农历生日。

## 安装与限制

[Release 与 IPA 下载](https://github.com/tsumon/reminder-app-ios/releases/tag/v2.11.1)。主应用与小组件均为 `2.11.1 / build 75`；Bundle ID（`com.reminder.app`、`com.reminder.app.widget`）、App Group（`group.com.reminder.app`）、entitlements 与 unsigned IPA 打包方式完全不变，可直接使用原有自签/侧载工具覆盖安装。
