# iOS 2.11.0 · build 74

**极简奶油漫风（Minimalist Cream Comic）** 全量 UI 前端重构与 SwiftUI 模块化升级。

## 界面与前端架构升级

- **极简奶油漫风设计系统（`ComicDesignSystem`）**：
  - 自绘 45° 对角斜切多边形（`ChamferShape`）、`1.5pt` 暖浓咖墨线（`#472714`）与 `+2.2pt` 零模糊硬边偏移投影，搭配 `#F6E5C8` 暖杏底纸与 `#FFF5DF` 亮奶油面板，砍掉嵌套碎框与原生灰底表格，呈现 92%+ 通透留白。
  - 默认 **奶油橙**（`#F06A29` 配 `#27140B` 深咖印刷墨字）及 **抹茶奶纸、海盐汽水、莓果奶昔、黄油柠檬、复古电紫** 6 套漫风纸色板，以及 **暗夜暖琥珀（Nocturnal Ink）** 深色模式，切换即时生效。
- **全页面减法重塑与圆体排印**：
  - **首页**：无框通透顶栏/副栏与单线快录条、圆体双层立体投影 `#Count` 焦点大卡、底纸纯文字通知自检与已完成折叠行、无分割线「即将到来」清爽清单，以及单枚激活切角底栏。
  - **新建/编辑页**：彻底弃用原生灰底 `Form`，单张通透面板一屏完成核心排期设定，高级重响策略与未来排期预览按需折叠展开。
  - **日历、统计、AI 分镜与 WidgetKit 小组件**：无网格线切角月历、`#Streak` 打卡大字与 16 周暖色圆点热力图、漫风分镜 AI 对话气泡、全套切角二级设置页及小/中号桌面小组件全面统一。
- **前端模块化拆解**：移除历史遗留 `PlayfulUI` 与毛玻璃层，拆解千行级视图并独立抽离 `AIChatViewModel` 与工具执行器，100% 保持 SwiftData 数据模型、WebDAV v4 同步与跨端备份兼容。

## English

iOS **2.11.0 (build 74)** introduces the **Minimalist Cream Comic** frontend redesign and modular SwiftUI architecture: custom 45° `ChamferShape` ink-stroked cream panels (`#F6E5C8` / `#FFF5DF` / `#472714`) with crisp offset shadows, zero nested boxes, 6 live paper palettes (default Cream Orange) plus Nocturnal Ink dark mode, rounded display `#Count` hero cards, unlined event lists, custom single-sheet reminder editor replacing system `Form`, dot-matrix stats heatmap, comic-panel AI chat, and matching WidgetKit extensions. Bundle IDs, App Group, entitlements, and unsigned IPA delivery remain completely unchanged.
