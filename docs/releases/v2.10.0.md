# iOS 2.10.0 · build 73

**Warm-Paper & Deep-Teal** 界面与交互升级，以及核心排期、通知配额、农历、语言切换、本地恢复与跨平台备份增强。

## 界面与体验优化

- **全新设计语言与即时换肤**：统一浅色（`#F6F4EF` / `#FFFFFF` / `#E7E2D8`）与深色（`#111315` / `#1A1D20` / `#2A2F35`）纸感画布及细线边框，默认 Deep-Teal 主色（`#0F766E` / `#2DD4BF`）；切换主题色或外观/语言时保留当前所在 Tab 并注入真实语言上下文（修复系统日期控件语言不同步）。
- **首页更轻盈、卡片触达直觉**：紧凑顶栏与浮动 Tab 栏 `.safeAreaInset(edge: .bottom)` 协同适配不同字号/安全区；首页诊断卡去除 `List` 嵌套 `NavigationLink` 的重复右箭头；非一次性周期/日期提醒支持左滑「跳过本次」并加入触觉反馈；移除小组件等待状态下无效的「稍后」按钮并匹配 Deep-Teal 品牌色。
- **创建表单与周期选择器**：支持规则提醒时间自定义、`Array(0..<60)` 分钟滚轮选择与文字农历输入；识别新旧历双生日时可自动创建（公历）与（农历）两条独立提醒；周期网格改用一致的 SF Symbols 图标。
- **统计与本地备份恢复**：统计页改为顶部 Hero 概览卡与数字序号徽章，连续天数及 16 周热力图始终基于全量记录统计；「本地备份」新增一键「恢复」入口，支持快速回滚备份。

## 核心逻辑修复

- **节假日与调休补班**：`ReminderEngine.deferToWorkday` 引入工作日调休状态，调休上班日不再误判顺延。
- **跨年农历与规则周期**：`LunarCalendar.nextLunarBirthday` 与 `occursOnDate` 扩展至 `(currentLunarYear - 1)...(currentLunarYear + 8)`（含大月 30→29 日回退与 `除夕` 处理），支持按传入时分计算；`occursOnRule` 校验 `rulePeriod`。
- **通知配额防饥饿**：`ReminderPolicy.allocate` 采用三层调度优先级，避免远期预告占满 64 条系统配额导致近期活跃重试被饥饿丢弃，并去重后台漏响触发记录。
- **跨平台备份与同步**：`BackupHelper` 与 `ReminderMerge` 完整往返 `useAlarmKit` 字段；WebDAV 优化 HTTP 412 错误提示；更新检查优先匹配对应版本 Tag 资产；诊断页将模拟测试区隔离至 `-uitest`。

## English

Bundle identifiers, App Group, entitlements, and unsigned IPA delivery remain unchanged.
