# iOS 2.9 runtime captures

Actual app and Widget build on iPhone 17 Pro simulator, iOS 27.2 (24B8117), source version 2.9.0 / 71. RefreshUITests creates the example reminder through the actual natural-language input and editable form. The images are native runtime attachments from the successful UI test, not design concepts or HTML mockups. Notification permission was deliberately not granted: the health card truthfully displays the actual state. Rendering and UI tests do not prove physical notification delivery or signed in-place upgrade.
